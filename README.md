# Plataforma de Gestión de Actividades para un Centro Cultural

Proyecto desarrollado en Django para gestionar las actividades de un centro cultural municipal. La aplicación permite organizar actividades, usuarios inscritos, monitores, salas y responsables de sala de forma sencilla, sustituyendo la gestión tradicional en papel por una plataforma digital.

## Funcionalidades principales

- Gestión de actividades.
- Gestión de usuarios inscritos.
- Gestión de monitores.
- Gestión de salas y responsables.
- Inscripción y cancelación de usuarios en actividades.
- Filtros y búsquedas por tipo de actividad, monitor o usuario inscrito.
- Panel de administración de Django.

## Tecnologías utilizadas

- Python
- Django
- SQLite
- HTML y CSS
- Git y GitHub

## Estructura del proyecto

La aplicación está organizada siguiendo la estructura habitual de Django, utilizando modelos, vistas, formularios, rutas y plantillas para separar correctamente la lógica del sistema y la parte visual.
